# Regras de commit:

## Scripts:
    Para scripts utilizar a branch: 
    * **feat/script_{ nome da função/alteracao }**
## Sprites/animações:
    Para atualizaçoes de animaçoes, adiçoes ou remoção, utilizar a branch: 
    * **feat/sprites_{ nome do personagem e tipo de animacao, caso seja }**
## Organização de pasta:
    ** Atenção!! ** Ao organizar pastas, conferir os caminhos, ajustar e commitar
    Criacao de pastas, organizacao e remocao, utilizar a branch: 
    * **feat/path_{ motivo da organização/criação ou remoção }**

### Pontos de atenção para commits: 
    1. Sempre testar a nova adição antes de commitar
    2. Conferir caminhos
    3. Verificar se atende as regras de commit
